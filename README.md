# SalesIA Enterprise

Sistema web de gestión de ventas y analítica estadística.

- Frontend: React + TypeScript
- Backend: Python + FastAPI
- Base de datos: PostgreSQL

Desarrollo basado en las 16 fases del Plan Integral de Desarrollo.
